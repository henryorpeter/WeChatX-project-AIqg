# WeChatX Project AIqg

一个面向微信小程序的 AI 情感沟通分析工具。用户可以输入聊天内容或关系困惑，应用会给出情绪类型、风险等级、对方可能心理、当前处境分析、建议回复和不建议表达的内容，帮助用户用更温和、有边界的方式处理关系沟通。

## 功能特性

- 情感分析：首页输入聊天记录或关系描述，生成结构化分析结果。
- 场景快捷填充：内置常见关系场景，方便快速体验分析流程。
- 风险提示：按低、中、高展示沟通风险，并对极端内容优先给出安全提醒。
- 回复建议：提供多条可参考的高情商回复，以及需要避免的表达。
- 历史记录：自动保存最近分析记录，支持筛选、搜索、查看详情和删除。
- 个人页概览：展示基础统计信息和功能入口。
- 本地 mock 模式：默认不请求线上 AI 服务，便于本地预览和开发。

## 运行方式

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本仓库根目录。
4. AppID 可以先使用测试号或游客模式；当前 `project.config.json` 中为 `touristappid`。
5. 点击编译，即可在开发者工具中预览。

## AI 接口说明

当前项目默认使用 mock 分析：

```js
const API_CONFIG = {
  useMock: true,
  endpoint: ''
};
```

如需接入真实 AI 服务，请在 `utils/analyze.js` 中将 `useMock` 改为 `false`，并把 `endpoint` 配置为你自己的后端 HTTPS 地址。

注意：不要把 API Key 放在小程序前端代码中。真实密钥应保存在服务端、云函数或后端环境变量里，小程序只请求自己的后端接口。

## 安全与边界

本项目的分析建议仅用于沟通参考，不替代心理咨询、法律意见或紧急救助。代码中已经对自伤、伤人、威胁等极端关键词做了基础识别，并优先提示用户联系现实中的可信任人员或当地紧急服务。
